# Service Certificates

Generate professional service certificates for your clients.

## What is a Service Certificate

A service certificate is a formal document that records the services performed on a client's vehicle. It includes:

- Workshop information (name, address, city)
- Client details (name, email, phone)
- Vehicle information (description, license plate)
- Services performed (dates, descriptions, status)
- Parts used (names, quantities, brands)

This is useful for:
- Providing clients with official service records
- Warranty documentation
- Insurance claims
- Vehicle resale documentation

## Generating a Certificate

Navigate to **Service Certificates** in the sidebar.

<!-- Screenshot: Service Certificates page -->

### Step 1: Search for Client/Vehicle

Use the search bar to find the relevant repair order. You can search by:

- Client name
- License plate
- Vehicle description
- Repair description

The list filters in real-time as you type.

### Step 2: Select a Repair

From the filtered list, click on the repair you want to generate a certificate for.

### Step 3: View Certificate Data

A detail modal opens showing the certificate preview:

| Section | Content |
|---------|---------|
| Workshop Header | Name, address, city |
| Client Info | Name, email, phone |
| Vehicle Info | Description, license plate |
| Services | List of service entries with dates and descriptions |
| Parts Used | Parts list with quantities and brand/model info |

<!-- Screenshot: Certificate detail modal -->

### Step 4: Download PDF

Click **Download PDF** to generate and download the certificate as a PDF file.

## Certificate Content Overview

The generated PDF contains:

### Header
- Workshop name
- Workshop address and city
- Certificate title

### Client Section
- Client name
- Client email
- Client phone

### Vehicle Section
- Vehicle description
- License plate

### Services Table

| Column | Description |
|--------|-------------|
| Date | Service date |
| Description | What was done |
| Diagnosis | Technical findings |
| Status | Repair status |

### Parts Used Table

| Column | Description |
|--------|-------------|
| Part Name | Name of the part |
| Quantity | Units used |
| Brand | Product brand |
| Model | Product model |
| SKU | Product SKU |

### Footer
- Generation date and time
- "Generated by WorkshopManager" watermark

## Searching for Repairs

The search is case-insensitive and matches against:

- Customer name
- License plate
- Vehicle description
- Repair description

Example: Typing "honda" will show all repairs where the vehicle description contains "Honda".

## Tips

- Generate certificates after marking a repair as **Completed**
- Ensure all parts used are recorded before generating the certificate
- Include a diagnosis for a more professional certificate
- Certificates can be re-generated at any time with updated information
