# Supplier Management

Manage your parts and materials suppliers.

## Viewing Suppliers

Navigate to **Suppliers** in the sidebar.

<!-- Screenshot: Suppliers page with table -->

### Supplier Table

The supplier list displays as a data table with columns:

| Column | Description |
|--------|-------------|
| Name | Supplier company name |
| Contact | Contact person name |
| Email | Email address |
| Phone | Phone number |
| Tax ID | RUT/Tax identification |
| Status | Active or Inactive |

## Creating a Supplier

1. Click **+ New Supplier** button
2. Fill in the supplier details
3. Click **Save**

<!-- Screenshot: Create supplier modal -->

### Supplier Fields

| Field | Required | Description |
|-------|----------|-------------|
| Name | Yes | Company/supplier name |
| Contact Person | No | Primary contact name |
| Email | No | Email address |
| Phone | No | Phone number |
| Address | No | Physical address |
| Tax ID | No | RUT or tax identification number |
| Payment Terms | No | Payment terms (e.g., "30 días", "Contado") |

## Editing Supplier Details

1. Click the **Edit** button (pencil icon) on a supplier row
2. Modify the fields
3. Click **Save**

## Linking Suppliers to Products

Suppliers are linked to products at the product level:

1. Go to **Products**
2. Create or edit a product
3. Select a supplier from the **Supplier** dropdown
4. Save the product

This establishes a relationship between the product and its supplier for tracking purposes.

### Benefits of Linking

- Track which supplier provides which products
- Identify preferred suppliers for reordering
- Analyze supplier performance over time
